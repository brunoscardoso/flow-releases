# Flow — Releases

Download and update feed for **Flow**, the plan-flow IDE (macOS, Apple Silicon).

- **Install**: download the latest `.dmg` from [Releases](../../releases/latest), open it, drag Flow to Applications.
- **Updates**: the app checks this repo's release feed (`latest-mac.yml`) and updates itself in-app — no manual downloads needed after the first install.

Source code lives in a private repository; this repo hosts release artifacts only.
